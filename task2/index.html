المقدمه

لغة JavaScript من ابتكار هو Brendan Eich وكان يعمل في شركة Netscape، وابتكر اللغة كإضافة للغة HTML وكانت تعمل في متصفح Netscape Navigator الإصدار الثاني. وكان الاسم الخاص بالجافا سكربت في البداية هو Mocha، ومع صدور الإصدارات الأولية للجافا سكربت حصلت على اسم LiveScript، ثم أخيراً حصلت على اسم JavaScript، وهناك فرق شائع بين لغة Java ولغة JavaScript. لغة JavaScript من لغات Interpreted Language، يعني لغة بتحتاج لمترجم عشان يترجم أكواد اللغة عشان تتعامل مع الكمبيوتر، والمترجم هو Browser أي المتصفح أيا كان نوعه. ولغة JavaScript تدعم البرمجة الكائنية وهي Object Oriented Programming وهي OOP

ما المقصود بـ JavaScript؟

ظهرت لغة JavaScript لإحشاء صفحات ويب حيوية وتفاعلية. تسمى البرامج المكتوبة بلغة JavaScript بالسكتات (scripts)، ويمكن كتابتها بشكل مباشر ضمن شيفرة HTML لصفحة الويب ليتم تنفيذها تلقائيا عند تحميل الصفحة، ولا تحتاج هذه السكتات إلى تحضير خاص أو تصريف مسبق وإنما تتم كتابتها ثم تنفيذها كنص عادي. هذا الأمر يميز لغة JavaScript عن لغة برمجية أخرى تشبهها بالاسم تدعى Java.

لماذا سميت javascript

عندما ظهرت لغة JavaScript، كان لها اسم مختلف وهو «LiveScript» ولكن الشعبية الكبيرة للغة Java في تلك الفترة دفعت إلى تغيير اسم اللغة إلى JavaScript بهدف إظهارها بصورة «الأخ الصغير» للغة Java واكتساب بعض الشهرة منها. ومع تطور لغة JavaScript، أصبحت لغةً مستقلة بشكل كامل ولها مواصفات ومعايير خاصة بها تُسمى «ECMAScript»، ولم يعد لها أي علاقة بلغة Java. في الوقت الحالي لا يقتصر تنفيذ لغة JavaScript على المتصفح وإنما من الممكن تنفيذها ضمن الخادوم أيضًا، أو أي جهاز يحتوي على برنامج خاص يسمى محرك JavaScript. يحتوي المتصفح على محرك مدمج ضمنه عادةً ما يسمى بآلة JavaScript الافتراضية وله أسماء تختلف باختلاف المتصفحات. فمثلًا يسمى المحرك باسم: V8 في متصفحي Chrome و Opera وباسم SpiderMonkey في المتصفح FireFox. Trident و Chakra في إصدارات مختلفة من IE، ويسمى ChakraCore في MicroSoftEdge، ويسمى Nitro و SquirrelFish في متصفح Safari …إلخ.

كيف تعمل محركات JavaScript طريقه عمل المحركات معقده وتتألف م ثلاث مراحل اساسيه

  • بدايةً، يقرأ المحرك (إذا كان التنفيذ يتم عن طريق المتصفح فالمحرك مدمج ضمنه) أو يفسر (بمعنى أدق) السكربت، ثم
  • يحول السكربت إلى لغة الآلة (عملية التصريف)، ثم تُنفَّذ شيفرات الآلة بشكل سريع.
  • يحسّن المحرك كل مرحلة من هذه العملية عن طريق مراقبة السكربت المترجم أثناء تنفيذه، وتحليل تدفق البيانات وفق السكربت ثم يقوم بتحسين شيفرة الآلة الناتجة وفقًا للمعرفة التي قام باكتسابها مما يساعد على زيادة سرعة تنفيذ السكربت.

مميزات لغة JavaScript

  • سهولة الاستخدام والتعلم.
  • تعمل على معظم متصفحات الإنترنت.
  • تساعد في إنشاء صفحات ويب تفاعلية.
  • تعمل مع HTML وCSS.
  • تستخدم في تطوير المواقع والتطبيقات.

عيوب لغة JavaScript

  • قد تختلف بعض خصائصها بين المتصفحات.
  • قد تؤدي الأكواد غير المنظمة إلى بطء الموقع.
  • تحتاج إلى تحديث مستمر للمهارات.

استخدامات JavaScript

تستخدم JavaScript في تطوير مواقع الويب، سواء في الواجهة الأمامية أو الخلفية، كما تستخدم في إضافة الأزرار التفاعلية والتحقق من البيانات وإنشاء تطبيقات الويب.

الخاتمة

​وفي النهاية، تُعد لغة الجافا سكربت من أهم لغات البرمجة في العصر الحديث، حيث تساعد في تطوير مواقع الويب وجعلها أكثر تفاعلاً وسهولة في الاستخدام، كما تتميز بمرونتها وتعدد استخداماتها، ولذلك فهي من اللغات المهمة التي يجب تعلمها لكل من يرغب في دخول مجال البرمجة وتطوير المواقع. ​أُوچدت لغة JavaScript في البداية كلغة يتم تنفيذها فقط من قبل المتصفح ثم تطورت وأصبح من الممكن تنفيذها ضمن بيئات مختلفة عبر Node.js. ​اليوم، تملك لغة JavaScript مكانة كبيرة وخاصة بسبب دعمها من قبل معظم المتصفحات واندماجها الكامل مع HTML وCSS. ​هنالك العديد من اللغات التي تُحول إلى JavaScript وتوفر مزايا خاصة، لذا ننصحك بالاطلاع عليها ولو بشكل سريع بعد تمكنك من لغة JavaScript. ​(ترجمة - وبتصرف- للفصل An Introduction to JavaScript من كتاب The JavaScript Language)
